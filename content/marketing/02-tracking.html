Cài đặt và kiểm tra tracking

1. Google Analytics

  1. Trong GA4, tạo/chọn property cho Divergency và Web data stream. Dùng URL chính của project Kickstarter.
  2. Vào Admin → Data streams → chọn stream; sao chép Measurement ID dạng G-…, dán vào Tracking ID ở Kickstarter → Promotion.
  3. Trong cùng stream, mở Measurement Protocol API secrets → Create; dán Secret value vào ô API secret trên Kickstarter.

Nguồn: Kickstarter: cài GA4; Google: tạo API secret.

2. Meta Pixel và Conversions API

  1. Trong Meta Events Manager, tạo/chọn nguồn Web cho Divergency. Nếu tạo mới, chọn kết nối thủ công với Meta Pixel và Conversions API.
  2. Ở Settings, lấy Dataset/Pixel ID và dán vào ô Pixel ID của Kickstarter. Kickstarter đã có phần tích hợp code.
  3. Vẫn nguồn đó: Settings → Conversions API → Set up direct integration → Generate access token. Dán token vào ô tương ứng trên Kickstarter. Nếu không thấy nút, kiểm tra quyền quản trị.

Nguồn: Kickstarter: Pixel và Kickstarter: CAPI. Token phải thuộc nguồn dữ liệu dùng với Pixel đã chọn.

Giữ API secret và access token trong tài khoản quản trị. Không dán chúng vào tài liệu public, HTML, Git hoặc ảnh chụp chia sẻ. Tab này chỉ chứa hướng dẫn. Google yêu cầu giữ API secret riêng tư.

3. Kiểm chứng bằng hành động thực tế

Mở trang pre-launch công khai bằng trình duyệt, ghi giờ và URL vừa mở; kiểm tra GA4 Realtime/Events và Meta Events Manager. Khi thử “Notify me on launch”, dùng tài khoản người xem chưa follow và tự chọn đồng ý tracking. Dữ liệu có thể đến chậm: GA4 tối đa 24 giờ; Meta từ vài phút đến vài giờ. Không tự đánh dấu hoàn tất chỉ vì đã bấm Save.

CAPI vẫn tuân theo lựa chọn tracking của người xem. Nếu thấy pledge bị đếm đôi, xem Diagnostics của Meta và nhờ Kickstarter kiểm tra tích hợp; chưa tăng ngân sách khi số liệu còn bất thường.

4. Link riêng cho mỗi kênh

Tạo custom referral tag trong Promotion trước launch hoặc Dashboard khi live; lưu đúng URL Kickstarter sinh ra. Báo cáo referral cho biết pledge và số tiền, không có lượt click. Dùng GA4 để bổ sung traffic. Hướng dẫn referral tags của Kickstarter.
